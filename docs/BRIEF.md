## The game in one page (verified against SDK sources; numbers from the handbook digest)

- **Draft phase**: each team picks 3–5 champions (map decides `draft::team_size()`), simultaneous
  picks per round, no duplicates within a team; the enemy may mirror. 11 selectable
  `champion_draft` values: Ryth 0, Vesper Vale 1, Vendetta 2, Cassi&Issac 3 (ONE pick = TWO
  bodies, both die if either dies), Stellar 4, Prism 5, Marcella 6, Willow 7, Ren 8, Varg 9, Tavi 10.
  Full map, camps and altars are visible during draft. First draft turn has 10× fuel (1,000,000).
  Draft bot may write **1,024 bytes of draft memory**, read-only by every champion bot afterwards.
  Each champion runs its own WASM instance (`main()` loops: act, `cambc::end_turn()`); no shared
  globals. **8 bytes of live shared memory** per team is the only in-game channel.
- **Map**: 30×30 to 100×100, `map::symmetry()` (horizontal/vertical/rot180). Terrain bitboards:
  walls (block move+sight), holes (block move, not sight; dashes cross them), bushes (walkable,
  hide units from outside), altars (not walkable; tribute from the 8 neighbours,
  `constants::submit_gems_range`). Each team has a spawn region (shop + heal there).
  Chebyshev distances everywhere. Vision radius 8 per champion with shadowcasting; each champion
  gets one free permanent ward (vision 6, place within 2, 1-round cooldown, replacing moves it).
- **Camps** (`map::camp_groups()`): groups of monsters at fixed spawn tiles. Kill every member
  of the group, then stand on the cleared tiles uncontested for `capture_time` (5) rounds to
  receive the group's `gem_value()`/`gold_value()` (split among allies present). Group respawns
  `max_respawn_timer()` rounds after capture. Monsters: gem cluster 500 HP/0 dmg/24 gems,
  gold cluster 500/0/35 gold, wolf 1350 HP/20 dmg/22 gems+90 gold, elk 2400/60/36 gems+160 gold,
  monolith 20000/200/200 gems+300 gold. Monsters are range 3, don't chase, sleep after no
  champion in range for 2 rounds, wake as a group when damaged.
- **Turn** (per champion, teams alternate execution slots, order by `set_priority` then draft
  order): one walk (1 tile, 8-dir), one basic attack (melee range 1; ranged range 3 but a ranged
  walk and attack exclude each other), ONE successful ability cast across the two slots
  (8-round cooldown each; some abilities `exclusive_with_movement`), ward, consumable, shop.
  Attack-reset abilities restore the basic attack (attack → reset → attack). Kills grant the
  killer the victim's whole carried bag + 50 gold. Death = 60 rounds out (shop while dead).
- **Scoring**: carried gems are unsecured. `submit_gems(altar)` channels ceil(bag/10) rounds
  (damage does NOT cancel; stun, death, or an enemy **altar lock** does). Recall channels 5 rounds
  (damage cancels). Altar lock: 10 gold consumable, placed within range 2 of an altar, blocks enemy
  tributes until broken by 3 basic attacks. TP crystal: 10 gold, 3-round channel, 3-tile jump.
- **Gold/items**: shards cost 30 gold (Strength/Focus/Health in 7 families); 5 identical shards
  auto-combine into an emblem (passives: Monster +10% camp dmg, Durability −10% dmg taken,
  Treasure +20% gold, Jungle −30% camp dmg taken, Home faster recall, Power/Bruiser none).
  Shop only on spawn (Tavi shops anywhere). Spawn heals at end of turn. 2000-round cap;
  tiebreaks: tributed gems → lifetime gold → kills → team B.
- **Champions** (base HP/Str/Focus; kits — verify exact numbers via `champion_designs()`):
  Ryth 1200/50/100 melee, reset + r4 AoE dmg+stun, +1 Str per 100 bonus HP ·
  Vesper 900/45/100 ranged, +20% gold, reset + dash · Vendetta 800/70/100 melee, reset + 2-step
  dash, camp kills refresh both cooldowns · Cassi 700/30/70 ranged (r4 dmg 2×Focus, walk-compatible
  r4 stun) & Issac 900/40/100 melee (reset, dash) · Stellar 750/35/100 ranged, r4 200 single-target
  and r4 140 AoE damage spells (both exclude walking) · Prism 700/35/80 ranged, +0.2 Focus per
  carried gem · Marcella 1200/45/50 melee, stun-immune, reset-with-stunning-hit + r4 2×Focus ·
  Willow 700/45/105 ranged, heals another ally 3×Focus r4 (walk-compatible) + reset ·
  Ren 900/40/100 melee, retaliates 20 per hit taken, r4 125 dmg+stun, dash ·
  Varg 1000/50/100 melee, basic attacks splash full Str to radius 1, 250 shield (5 turns) + reset ·
  Tavi 750/35/100 ranged, reset + r4 220 dmg+stun, buys shards in the field.
- **Fuel**: wasmtime fuel ≈ instructions; 100k per C++ turn (200k first play turn, 1M first
  draft turn). Running out **suspends mid-instruction and resumes next round** — the rest of the
  turn is forfeited and the code then acts on stale state. Check `cambc::fuel_remaining()` and
  always end the turn with margin. Engine host calls (bitboard ops, distance fields) run natively
  in the engine; measure their fuel cost before relying on them in loops.

## Our plan (what every agent builds towards)

1. `bots/apex` (C++): draft-time global plan (routes per champion stored in draft memory),
   complete kit execution (resets, spells, shields, dashes), correct capture/tribute state
   machines, opportunity-cost banking, altar locks + wards, kill-steal combat with a threat model,
   zero fuel suspensions, zero faults.
2. `tools/arena.py`: local tournaments over all 17 maps × both sides, parallel, with per-map tables.
3. Sparring bots in `bots/spar-*` for regression gates.
4. Everything measured. Promote changes only on panel wins.

Conventions: C++20, one `src/` folder per bot, `main.cpp` dispatches draft vs play, print
one compact telemetry line per champion every 100 rounds (`round fuel_min suspensions role gems`).
Never leave the bot in a state where an exception skips `end_turn()`.
